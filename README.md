### About The Mod:
This Mod Allows You To Edit Your Minecraft Skins **IN-GAME!** We Build An 3D Canvas To Make The Edit Process Very Quick And Simple!

### Instalation:

1. Download Minecraft: Java Edition.
2. Download The [Fabric Loader](https://fabricmc.net/use/installer/) (If You Use An Minecraftlauncher Like Prism Or The Modrinth App, Please Watch Special Tutorials For Them).
3. Download The Dependencie [Fabric API](https://modrinth.com/mod/fabric-api) And The [Mod](https://modrinth.com/mod/mc-skins/versions)
4. Put Both Jars Into The ```mods``` Folder Inside The Minecraft Folder.
5. Launch The Game!
